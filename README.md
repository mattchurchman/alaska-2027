# Alaska 2027 trip planner

A planning site for a family Alaska cruise in June 2027: routes, ships, dates, day-by-day activities and honest costs, with a source and check date on every price.

**Site:** https://mattchurchman.github.io/alaska-2027/ (open it in Safari on iPhone or iPad).

The site has four screens so far: **Ideas** (kinds of route and glaciers), **Route** (map), **Line & ship** (photos, facts, ship-tour videos) and **Dates** (every departure with its two-cabin price). Tap **Share** on any screen to send a link that opens that exact view. Day-by-day plans and full trip costs come next (see `PLAN.md`).

## How it's kept up to date
Prices and research live in `data/`. Claude updates them in short work sessions, one phase at a time, and each change is published automatically. Nobody needs to edit files by hand.
